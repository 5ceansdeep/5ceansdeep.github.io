현장실습 · 컨텍스트 관리

큰 레거시 코드에서 AI가 길을 잃지 않게

코드가 방대해 작업할수록 맥락과 예외 케이스가 쌓였습니다. 업무 규칙과 작업 맥락을 마크다운 문서로 정리하고, 규칙에 따라 컨텍스트를 정리해 주는 Claude Code 스킬(/refresh)을 직접 만들었습니다. 작업하면서 문서를 보강하고 규칙과 훅을 계속 추가했고, 이 방식을 프롬프트로 정리해 동료와 공유했습니다.

  • Claude Code
  • 스킬 · 룰 · 훅
  • 마크다운 문서화

현장실습 · 검증

AI가 만든 결과를 그대로 믿지 않기

AI로 구현한 화면은 Playwright로 화면 흐름을 먼저 자동 검증하고, 실제 사용자 흐름은 직접 확인했습니다. 폐쇄망처럼 AI 없이 코드를 다뤄야 할 상황에 대비해, AI가 짠 코드를 두고 문제를 내 주는 학습 도구도 직접 만들었습니다.

  • Playwright
