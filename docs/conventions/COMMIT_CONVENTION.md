# 커밋 컨벤션

yjj_project 커밋 컨벤션을 그대로 따른다.

## 형식

```
[TYPE] 제목

본문(선택)
```

- 제목과 본문 사이에 빈 줄 하나.
- 제목은 50자 이내, 끝에 마침표 없음.
- 제목은 "추가", "수정", "구현"처럼 무엇을 했는지로 끝냄.
- 본문은 72자 안팎에서 줄바꿈. 어떻게보다 무엇을, 왜 바꿨는지 씀.
- 커밋 하나에는 한 가지 성격의 변경만 담음. 섞이면 나눠서 커밋.

## 타입

| 타입 | 쓰는 경우 |
|---|---|
| `[FEAT]` | 새 기능, 새 화면 |
| `[FIX]` | 버그 수정 |
| `[REFACTOR]` | 동작은 그대로, 구조만 변경 |
| `[STYLE]` | 코드 포맷, 세미콜론 등 동작과 무관한 변경 |
| `[DESIGN]` | UI 모양, 스타일(CSS) 변경 |
| `[DOCS]` | 문서 추가, 수정 |
| `[TEST]` | 테스트 추가, 수정 |
| `[CHORE]` | 설정, 스크립트, 패키지 등 기타 작업 |

## 예시

```
[FEAT] 랜딩 3D 사원증 구현

React Three Fiber와 rapier로 끈과 카드를 물리로 연결한다.
- 카드를 잡아당기면 끈 길이 안에서만 움직임
- 카드 잡는 동안 도트 락앤롤 손 커서
```

```
[CHORE] GitHub Pages 배포 워크플로 추가
```
